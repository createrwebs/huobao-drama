PART 3 : ASSETS & VIDEO
5
สกัดสินทรัพย์ & สร้างภาพ Character Turnaround เพื่อล็อกหน้า
คลิกปุ่ม "สกัดตัวละคร / ฉาก / อุปกรณ์" ระบบจะดึงรายชื่อสิ่งที่ต้องใช้ในตอนนี้ออกมา พร้อมสร้าง Character Reference Sheet แบบ 3 มุมมอง (หน้า, ข้าง 90 องศา, หลัง) เพื่อล็อกเสื้อผ้าและใบหน้าให้ตรงกันตลอดทั้งเรื่อง
ภาพที่ 3.1: หน้าคลังสินทรัพย์ พร้อมปุ่มส่ง Reference ไป Google Flow และปุ่มอัปโหลดรูปภาพ
6
แตกสตอรี่บอร์ด เลือก Model วิดีโอด้านบน & สั่งเรนเดอร์
ในแท็บ "การผลิตวิดีโอ" AI จะแตกบทเป็นมุมกล้องรายช็อต พร้อมระบุความยาว (เช่น 10s) และจับคู่แท็กตัวละคร @Character ให้อัตโนมัติ
🎯 เมนูเลือกโมเดลวิดีโอ (แถบด้านบน)
สลับโมเดลได้ทันทีตามต้องการ:
• Google Flow Veo 2: ฟรีเครดิต คุณภาพสูง คมชัด
• Seedance 2.0: ภาพยนตร์สมจริง เคลื่อนไหวมิติสูง
• Wan 3.0 / MiniMax H3: อารมณ์และการแสดงยอดเยี่ยม
  • ✓ คลิก "สร้างวิดีโอทั้งหมด" เพื่อเรนเดอร์ทั้งชุดในคลิกเดียว
  • ✓ สามารถกด "สร้างใหม่" เฉพาะช็อตที่ไม่ถูกใจได้ทันที
ภาพที่ 3.2: หน้าจอสตอรี่บอร์ดพร้อม Dropdown สลับโมเดลวิดีโอด้านบน

PART 4 : EXPORT & PRO TIPS
7
ตรวจสอบไทม์ไลน์ รวมคลิปด้วย FFmpeg และดาวน์โหลด
ในแท็บ "รวมวิดีโอและส่งออก" คุณสามารถพรีวิวคลิปทุกช็อตในไทม์ไลน์ แล้วคลิกปุ่ม "รวมวิดีโอที่เลือก" เครื่องยนต์ FFmpeg ในโปรแกรมจะทำการปรับขนาดความละเอียด เฟรมเรต และเชื่อมต่อคลิปทั้งหมดเป็นไฟล์ .mp4 พร้อมเสียงและซับไตเติล
ภาพที่ 4.1: หน้าต่างรวมคลิปทั้งตอน มีปุ่ม "ดาวน์โหลด" และปุ่ม "นำเข้า/เปลี่ยนวิดีโอ"
💡
เคล็ดลับขั้นเซียน: ล็อกตัวละครให้นิ่ง 100% & ประหยัดค่าใช้จ่าย API
หากคุณต้องการคุมหน้าตาตัวละครให้สวยเป๊ะตามใจสั่ง 100% หรือไม่อยากเสียเครดิต API เยอะ สามารถใช้เทคนิค Manual Hybrid Workflow:
1. คัดลอก Prompt ไปสร้างรูปข้างนอก
คัดลอก Prompt ตัวละครจากแท็บ Assets ไปเจนใน Midjourney, Fooocus หรือ ComfyUI แล้วกดปุ่ม "อัปโหลด" ที่การ์ดตัวละครเพื่อนำรูปกลับเข้ามาแทนที่ ใบหน้าและชุดจะนิ่งสนิท 100%!
2. เจนวิดีโอภายนอกแล้วนำเข้า
สำหรับช็อตสำคัญ สามารถนำ Prompt และ Reference ไปสร้างในแพลตฟอร์มที่คุณมีบุฟเฟต์ แล้วกดปุ่ม "เปลี่ยนวิดีโอ / นำเข้าวิดีโอ" ในหน้า Export เพื่อให้ FFmpeg ช่วยรวมคลิปให้โดยไม่เสียเครดิตเพิ่ม!
⚡ สรุป: ใช้ Tora StoryVDO คิดบท + แบ่งช็อต + ต่อคลิป | ใช้ AI ภายนอกคุมหน้าตา = ประหยัดเงิน & ผลงานเป๊ะ 100%
