# แนวทางความต่อเนื่องของสตอรี่บอร์ด (Storyboard Continuity)

ดัดแปลงแบบเลือกสรรจาก zenstory-ai/drama-skills (commit c2426e03c0e7722bebcc6a488b6658dc38c65ac3, MIT License)
เครื่องมือ ข้อมูล และโครงสร้างเนทีฟเดิมยังคงมีผลบังคับใช้สูงสุด

## 1. ห่วงโซ่การกระทำของช็อตย่อย (จุดเริ่มต้น → การกระทำหลักที่มองเห็นได้ → จุดสิ้นสุด)
ในแต่ละช่วงสตอรี่บอร์ดเดิม (8-15 วินาที, 2-4 ช็อตย่อย):
- สำหรับแต่ละช็อตย่อยใน `description` (`【ช็อต N】`):
  1. **จุดเริ่มต้น (Initial State)**: ตำแหน่ง ท่าทาง มือ ทิศทางสายตา และอุปกรณ์ที่ถืออยู่ ณ จุดเริ่มต้น
  2. **การกระทำหลักที่มองเห็นได้หนึ่งอย่าง (One Main Visible Action)**: การเปลี่ยนผ่านทางกายภาพที่มองเห็นได้ชัดเจนหนึ่งอย่าง (ไม่ใช้คำบรรยายจิตวิทยาหรือนามธรรม)
  3. **จุดสิ้นสุด (End State)**: สภาพผลลัพธ์ของท่าทางและวัตถุ ซึ่งสะท้อนลงใน `result` และเชื่อมโยงเป็นจุดเริ่มต้นของช็อตย่อยถัดไป
- วัตถุและตัวละครต้องไม่หายตัวหรือสลับตำแหน่งโดยไม่มีเหตุผลทางกายภาพ

## 2. การล็อกความต่อเนื่อง (Continuity Locks)
รักษาจุดยึดโยงทางภาพให้สม่ำเสมอตลอดช็อตที่เกี่ยวข้อง:
- **รูปลักษณ์และการแต่งกาย**: ใช้ข้อความล็อกเดิมจากข้อมูลตัวละคร (`appearance`, `styling`) ซ้ำอย่างแม่นยำ
- **สภาพแวดล้อม แสง และภูมิศาสตร์ของฉาก**: รักษาทิศทางแสง อุณหภูมิสี และการจัดวางพื้นที่ตามข้อมูลฉาก
- **อุปกรณ์ในมือและการสัมผัส**: บันทึกว่าใครถืออะไร มือข้างไหนถือ และวางไว้ที่ใด
- **ทิศทางสายตา (Gaze)**: รักษาแนวสายตาและทิศทางบนหน้าจอระหว่างคู่สนทนา
- **ห้ามคิดข้อเท็จจริงขึ้นเอง**: หากรายละเอียดรูปลักษณ์หรืออุปกรณ์ไม่มีในบริบท ให้รายงานข้อเท็จจริงที่ขาดหายอย่างชัดเจนแทนการคาดเดา

## 3. กฎของภาพเฟรมแรก (First-Frame Rule)
- คำอธิบายภาพเฟรมแรก (`image_prompt`) ต้องสะท้อนเฉพาะ **จุดเริ่มต้น (Initial State)** เท่านั้น
- ห้ามใส่การกระทำระหว่างช็อตหรือผลลัพธ์บั้นปลายลงในพร้อมท์ภาพเฟรมเริ่มต้น

## 4. การแก้ไขแบบไม่ทำลายและการรักษา ID เดิม
- เมื่อแก้ไขสตอรี่บอร์ด ให้รักษา ID เดิม ลำดับเดิม และแอสเซทของช่วงที่ไม่ได้รับผลกระทบไว้เสมอ
- `save_storyboards` ที่ใช้ `replace_existing=true` เป็นการลบข้อมูลเดิม: ห้ามแนะนำหรือสั่งเขียนทับสื่อที่สร้างเสร็จแล้วโดยไม่มีเจตนาชัดเจนจากผู้ใช้
- ใช้ `update_storyboard` สำหรับการปรับปรุงเฉพาะช่วง
