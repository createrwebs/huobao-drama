# คู่มือการแยกสตอรี่บอร์ด

## นิยามหลัก: ช่วงสตอรี่บอร์ด (Storyboard Segment)

1 สตอรี่บอร์ด = 1 **ช่วงสตอรี่บอร์ด (Storyboard Segment)** = 1 งานสร้างวิดีโอ

- แต่ละช่วงมีความยาว **8-15 วินาที** และมี **2-4 ช็อตย่อย** ภายใน
- **อนุญาตให้ตัดสลับ**ระหว่างช็อตย่อย: เปลี่ยนขนาดภาพ มุมกล้อง หรือตัวแบบ โดยใช้การตัดชน (hard cut)
- ช็อตย่อย**ห้ามข้ามฉาก**: แต่ละช่วงเกิดขึ้นในฉากเดียวเท่านั้น (`scene_id` ผูกในระดับช่วง)
- แต่ละช็อตย่อยยาว 2-6 วินาที มุ่งเน้นที่หน่วยภาพเดียว (หนึ่งการกระทำ หนึ่งปฏิกิริยา หนึ่งโคลสอัพ)

## กระบวนการแยก (4 ขั้นตอน)

1. เรียกใช้ `read_storyboard_context` เพื่ออ่านบทละคร ตัวละคร ฉาก อุปกรณ์ และสตอรี่บอร์ดเดิม
2. **ระบุจังหวะการเล่าเรื่อง (Beats)**: ระบุจุดเปลี่ยนหรือจังหวะของบทก่อน เช่น [เปิดเรื่อง] [จุดเริ่มต้น] [ไคลแมกซ์] [บทสรุป] หรือการเปลี่ยนสถานที่/เปิดเผยความจริง/ระเบิดอารมณ์ **ขอบเขตของจังหวะจะบังคับให้ตัดช่วงสตอรี่บอร์ด** รวมช็อตย่อยในจังหวะเดียวกันไว้ในช่วงเดียวกัน อย่าแยกห่วงโซ่เหตุและผลออกจากกัน
3. **กำหนดปริมาณรวม**: ความยาวรวมเป้าหมาย = จำนวนตัวอักษรบทละคร ÷ 500 ตัวอักษร/นาที; จำนวนช่วง ≈ ความยาวรวม ÷ 12 วินาที (ยอมรับ ±20%)
4. **แยกช็อตย่อยในแต่ละช่วง**: ตัดช็อตย่อยเมื่อเปลี่ยนการกระทำ เปลี่ยนมุมมอง หรือเปลี่ยนตัวแบบ; เมื่อกรอกครบทุกฟิลด์แล้วให้เรียก `save_storyboards` เพื่อบันทึก

## ความยาวตามระดับจังหวะ

| ประเภทช่วง | ความยาว | คำอธิบาย |
|---|---|---|
| ช่วงเปลี่ยนผ่าน | 8-10 วินาที | เดินทาง วิวว่าง ภาพสร้างบรรยากาศ ทรานซิชัน |
| ช่วงเล่าเรื่อง | 10-15 วินาที | ดำเนินเรื่องปกติ บทสนทนา |
| ช่วงไคลแมกซ์/จุดสำคัญ | 12-15 วินาที | โคลสอัพ เปิดเผยความจริง ระเบิดอารมณ์ หักมุม; จังหวะช็อตย่อยช้าลง ช็อตเดียวอาจค้างได้ 4-6 วินาที |

## เกณฑ์ขั้นต่ำของความยาวบทพูด (กฎเข้มงวด)

**ความยาวช่วง ≥ จำนวนตัวอักษรบทพูดและเสียงบรรยายใน description ÷ 4.5 ตัวอักษร/วินาที + 2 วินาทีสำรองสำหรับการแสดง**

บทพูดที่ไม่พอดีต้องยกไปช่วงถัดไป ไม่อนุญาตให้อัดบทพูดที่แสดงไม่ทันลงในช่วยเดียว

## องค์ประกอบของสตอรี่บอร์ด

1. **ชื่อช็อต**: สรุปสั้นๆ 3-5 คำ (เช่น "สะดุ้งตื่นจากฝันร้าย")
2. **เวลา**: ช่วงเวลาเฉพาะ + คำอธิบายแสง
3. **สถานที่**: คำอธิบายฉากเต็ม + การจัดวางพื้นที่ + สภาพแวดล้อม
4. **ขนาดภาพ**: ขนาดภาพหลัก เช่น "ภาพระยะปานกลาง + โคลสอัพ"
5. **มุมกล้อง**: ระดับสายตา / มุมเงย / มุมก้ม / ด้านข้าง / ด้านหลัง
6. **การเคลื่อนกล้อง**: กล้องนิ่ง / ดันเข้า / ดึงออก / แพน / แทร็กกิ้ง
7. **คำอธิบายภาพ `description`**: บรรยายทีละช็อตย่อยเป็น `【ช็อต 1】…【ช็อต 2】…` สิ่งที่ผู้ชมเห็นและได้ยินจริง — ภาพ (ใคร + การกระทำ + ภาษากาย + สีหน้า) มาก่อน หากมีบทพูดให้ใส่เป็น "ชื่อตัวละครพูดว่า: "ข้อความ"" และ "เสียงบรรยาย: ข้อความ"
8. **ผลลัพธ์ภาพ `result`**: ผลลัพธ์ทันทีเมื่อสิ้นสุดช่วง
9. **บรรยากาศ `atmosphere`**: แสง + โทนสี + เสียง + อารมณ์โดยรวม
10. **ความยาว `duration`**: 8-15 วินาที และต้องผ่านเกณฑ์ขั้นต่ำของบทพูด
11. **การผูกฉาก**: หากตรงกับฉากเดิม ให้ระบุ `scene_id`
12. **การผูกตัวละคร**: ระบุ `character_ids` ผูกตัวละครที่ปรากฏ
13. **การผูกอุปกรณ์**: ระบุ `prop_ids` ผูกอุปกรณ์สำคัญที่ปรากฏ
14. **พร้อมท์วิดีโอ `video_prompt`**: บรรทัดแรกต้องเป็นส่วนหัว (Header) ที่ระบุตัวละคร เช่น `ตัวละคร: @ชื่อตัวละคร; ฉาก: @ชื่อฉาก.` ตามด้วยไทม์ไลน์ช่วงละ 3 วินาที (0-3s, 3-6s...)
