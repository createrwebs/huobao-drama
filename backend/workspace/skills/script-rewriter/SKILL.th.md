# คู่มือการดัดแปลงบทละคร

## หลักการดัดแปลง

1. **รักษาแก่นเรื่องหลัก**: ไม่เปลี่ยนเส้นเรื่องหลักหรือความสัมพันธ์ของตัวละคร
2. **เน้นความชัดเจนของภาพ**: เปลี่ยนการบรรยายแบบร้อยแก้วให้เป็นคำอธิบายฉากที่มองเห็นภาพได้
3. **ขับเคลื่อนด้วยบทสนทนา**: ใช้บทพูดดำเนินเรื่องและลดเสียงบรรยายให้น้อยลง
4. **ควบคุมจังหวะ**: แต่ละฉากยาว 30-60 วินาที เหมาะสำหรับวิดีโอสั้น
5. **ไม่ใช้ภาษาภาพยนตร์/มุมกล้อง**: ไม่มีขนาดภาพ มุม หรือการเคลื่อนกล้อง — ส่วนนั้นเป็นหน้าที่ของการแยกสตอรี่บอร์ด

## รูปแบบบทละครมาตรฐาน

```
## S01 | ภายใน · ร้านกาแฟ | โพล้เพล้

แสงยามเย็นส่องผ่านหน้าต่างบานกระจกเข้ามาในร้านกาแฟ ควันกรุ่นลอยจากถ้วยกาแฟบนเคาน์เตอร์

สมชาย นั่งคนเดียวที่โต๊ะมุมร้าน ก้มหน้ามองโทรศัพท์ ดูมีท่าทีกระวนกระวาย

เสียงกระดิ่งประตูดังขึ้นเมื่อ สมหญิง ผลักประตูเข้ามา เธอเห็นสมชายแล้วเดินเข้ามาด้วยรอยยิ้ม

สมหญิง: (ยิ้ม) รอนานไหม?
สมชาย: (เงยหน้า) ไม่หรอก เพิ่งมาถึงเหมือนกัน
```

### กฎของรูปแบบ

- `## S<ตัวเลข> | ภายใน/ภายนอก · สถานที่ | ช่วงเวลา` — หัวฉาก
- คำอธิบายการกระทำเขียนเป็นย่อหน้าปกติ — ไม่มีภาษามุมกล้องใดๆ
- `ชื่อตัวละคร: (สภาวะ/สีหน้า) เนื้อหาบทพูด` — รูปแบบบทพูด

### การอ้างอิงปริมาณเนื้อหา

บทละครมาตรฐานจะยาวกว่าเนื้อหาต้นฉบับประมาณ 20-30% โดยส่วนที่เพิ่มขึ้นมาจากหัวฉากและการจัดรูปแบบบทพูด ไม่ใช่การเขียนขยายความโดยไม่จำเป็น

## ขั้นตอนการดัดแปลง

1. เรียกใช้ `read_episode_script` เพื่ออ่านเนื้อหาต้นฉบับ
2. วิเคราะห์โครงสร้างเนื้อหา (สัดส่วนของบทพูด เสียงบรรยาย และเสียงในใจ)
3. เรียกใช้ `rewrite_to_screenplay` เพื่อทำการดัดแปลง
4. ตรวจสอบผลลัพธ์และยืนยันว่าเป็นไปตามรูปแบบบทละครมาตรฐาน
5. เรียกใช้ `save_script` เพื่อบันทึกผลลัพธ์สุดท้าย

## ข้อควรระวัง

- เสียงในใจสามารถแปลงเป็นสีหน้า/การกระทำของตัวละคร หรือเสียงพากย์ได้
- แบ่งบทบรรยายยาวๆ ออกเป็นหลายฉากสั้นๆ
- ตรวจสอบให้แน่ใจว่าทุกฉากมีจุดเปลี่ยนทางอารมณ์ที่ชัดเจน
- รักษาสไตล์ภาษาของตัวละครแต่ละตัวให้สม่ำเสมอ
- หมายเลขฉากเพิ่มขึ้นตามลำดับ (S01, S02, S03...)
- ช่วงเวลาต้องระบุชัดเจน (โพล้เพล้, กลางดึก, เช้าตรู่) — อย่าเขียน "กลางวัน" กว้างๆ
