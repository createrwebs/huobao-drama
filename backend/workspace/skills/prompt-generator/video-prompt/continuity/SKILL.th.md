# แนวทางความต่อเนื่องและแอสเซทอ้างอิงของพร้อมท์วิดีโอ (Video Prompt Continuity)

ดัดแปลงแบบเลือกสรรจาก zenstory-ai/drama-skills (commit c2426e03c0e7722bebcc6a488b6658dc38c65ac3, MIT License)
รูปแบบและโครงสร้างไปป์ไลน์เนทีฟเดิมยังคงมีผลบังคับใช้สูงสุด

## 1. รูปแบบเนทีฟและความซื่อสัตย์ต่อเนื้อหาเดิม
- คงรูปแบบที่ไปป์ไลน์ของระบบคาดหวัง:
  - บรรทัดส่วนหัว (Header): `ตัวละคร: @ชื่อตัวละคร (รูปลักษณ์, เสื้อผ้า); ฉาก: @ชื่อฉาก (แสง, สภาพแวดล้อม); อุปกรณ์: @ชื่ออุปกรณ์ (ลักษณะ)`
  - ไทม์ไลน์ช่วงละ 3 วินาที (`0-3s: ...`, `3-6s: ...`) ต่อเนื่องกันจนครบความยาวช่วงสตอรี่บอร์ด (8-15 วินาที, 2-4 ช็อตย่อย)
- ดึงข้อมูลจาก `description`, `duration`, และ `result` ที่มีอยู่จริงโดยไม่แต่งเติมเหตุการณ์ ตัวละคร หรือบทพูดขึ้นใหม่นอกเหนือจากสตอรี่บอร์ด
- ห้ามนำกฎความยาวช็อตเดี่ยวของระบบภายนอกมาใช้ขัดแย้งกับช่วงสตอรี่บอร์ดเนทีฟขนาด 8-15 วินาที

## 2. การปฏิบัติตามข้อจำกัดจริงของโมเดล
- ข้อกำหนดจริงของโมเดลวิดีโอปลายทางมีสิทธิ์สูงสุด
- ห้ามสร้างหรือทึกทักเอาเองเรื่องความยาวที่รองรับ ฟีเจอร์เสียง หรือขีดจำกัดของภาพอ้างอิงที่โมเดลไม่รองรับ
- แปลงอารมณ์และความรู้สึกให้เป็นการกระทำทางกายภาพที่มองเห็นได้ชัดเจน

## 3. ภาพอ้างอิงจริงกับข้อกำหนด Text-to-Video
- **แยกแยะภาพอ้างอิงจริงออกจากพร้อมท์ที่วางแผนไว้**:
  - แยกความแตกต่างระหว่างรูปภาพอ้างอิงที่มีอยู่จริง กับรูปภาพที่ยังไม่ได้สร้างหรือเป็นเพียงแผน
  - หากขาดรูปภาพอ้างอิงที่จำเป็น ให้ระบุรายการภาพที่ขาดอย่างชัดเจน
  - **ห้ามสลับโหมดเงียบๆ**: ห้ามเปลี่ยนจาก Image-to-Video (I2V) ไปเป็น Text-to-Video (T2V) โดยพลการ เว้นแต่ผู้ใช้มีเจตนาเลือกอย่างชัดเจน
- **ใช้เฉพาะบริบทอ้างอิงจริง**:
  - ยึดตามบริบทภาพอ้างอิงจริงในโครงการ ไม่สร้าง URL ปลอมหรือ ID อ้างอิงที่ไม่มีอยู่จริง
