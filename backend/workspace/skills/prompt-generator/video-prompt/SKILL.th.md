# พร้อมท์วิดีโอ (ช่วงสตอรี่บอร์ด → video_prompt)

สร้าง `video_prompt` เพื่อขับเคลื่อนการสร้างวิดีโอ AI จาก description ของช่วงสตอรี่บอร์ด (ซึ่งมีโครงสร้าง 【ช็อต N】 และบทพูด/เสียงบรรยาย) / atmosphere / duration **หนึ่งช่วงสตอรี่บอร์ด = หนึ่งวิดีโอความยาว 8-15 วินาที โดยอนุญาตให้ตัดช็อตภายในได้**: แต่ละช่วงเวลาต่อเนื่องกันอาจเป็นคนละช็อต (เปลี่ยนขนาดภาพ/มุมกล้อง/ตัวแบบ) แต่ตลอดช่วงสตอรี่บอร์ด**ห้ามข้ามฉาก**

## รูปแบบ

**บรรทัดแรกของ `video_prompt` คือส่วนหัว (Header)**: ต้องระบุบริบทภาพ รูปลักษณ์ และเครื่องแต่งกายของตัวละครและฉากอย่างละเอียด เพื่อให้โมเดลวิดีโอ (เช่น Google Flow, Veo) เข้าใจตัวตน รูปลักษณ์ และสภาพแวดล้อมได้อย่างชัดเจนและคงความสม่ำเสมอในทุกช็อต:
- **ตัวละคร**: ระบุ `@ชื่อตัวละคร (เพศ, วัย, รูปร่างหน้าตา ทรงผม สีผิว, เสื้อผ้าเครื่องแต่งกายที่สวมใส่ตาม appearance และ styling จาก read_storyboard_context)`
- **ฉาก**: ระบุ `@ชื่อฉาก (สภาพแวดล้อม ลักษณะสถานที่ ยุคสมัย แสง และบรรยากาศ ตาม prompt และ lighting จาก read_storyboard_context)`
- **อุปกรณ์**: เมื่อมีอุปกรณ์ปรากฏอย่างเด่นชัด ให้ระบุ `; อุปกรณ์: @ชื่ออุปกรณ์ (ลักษณะและสีของอุปกรณ์)`

```
ตัวละคร: @สมชาย (ชายไทยวัย 28 ปี รูปร่างสูงโปร่ง ผิวสองสี ผมสั้นสีดำ สวมเสื้อเชิ้ตขาวกางเกงสแล็คดำ), @สมหญิง (หญิงสาววัย 24 ปี รูปร่างสมส่วน ผิวขาว ใบหน้าหวาน ผมยาวดัดลอน สวมชุดเดรสสีครีม); ฉาก: @ร้านกาแฟ (คาเฟ่โมเดิร์นร่วมสมัย โต๊ะไม้สีน้ำตาล แสงแดดอบอุ่นส่องผ่านกระจกบานใหญ่).
0-3s: @ร้านกาแฟ, ภาพระยะใกล้, กล้องนิ่ง; @สมชาย ก้มหน้ามองโทรศัพท์ นิ้วเคาะโต๊ะเป็นจังหวะ สีหน้ากังวล
3-6s: ตัดสลับไปที่ภาพมุมกว้างของประตูหน้าร้าน; เสียงกระดิ่งประตูดังขึ้นเมื่อ @สมหญิง ผลักประตูเดินเข้ามา
6-9s: ตัดกลับมาที่ภาพระยะปานกลาง; @สมหญิง เดินยิ้มเข้ามานั่งลงตรงข้ามสมชาย; สมชายพูดว่า: "ในที่สุดเธอก็มา"
```

กฎของส่วนหัว:
- ดึงข้อมูลรูปร่างหน้าตา (appearance) และเครื่องแต่งกาย (styling) ของตัวละครจาก `read_storyboard_context` มาสรุปไว้ในวงเล็บหลัง `@ชื่อตัวละคร` เสมอ
- ระบุเฉพาะตัวละครที่ปรากฏจริงในสตอรี่บอร์ดนี้และฉากที่ผูกไว้เท่านั้น
- เมื่อมีอุปกรณ์ปรากฏอย่างเด่นชัด สามารถเพิ่มต่อท้ายได้ (เช่น `; อุปกรณ์: @จดหมาย (ซองจดหมายสีน้ำตาลปิดผนึกตราครั่ง)`)
- ส่วนหัวอยู่บรรทัดของตัวเอง ลงท้ายด้วยจุด ตามด้วยช่วงเวลา

แบ่งเป็นช่วงละ 3 วินาที แต่ละช่วงแยกบรรทัด ช่วงเวลาต้องต่อเนื่องกัน

## การจับคู่กับคำอธิบายสตอรี่บอร์ด

`description` เป็นแหล่งเนื้อหาเพียงหนึ่งเดียวของ video_prompt:
- แต่ละ `【ช็อต N】` ใน `description` จับคู่กับ **1-2 ช่วง 3 วินาทีที่ต่อเนื่องกัน** — ตามลำดับ ไม่ตกหล่น ไม่เพิ่มช็อตใหม่
- บทพูด/เสียงบรรยายดึงมาจาก "ชื่อตัวละครพูดว่า: "ข้อความ"" / "เสียงบรรยาย: ข้อความ" ใน `【ช็อต N】`
- การกระทำภาพตาม `description`; ใช้ `atmosphere` เพื่อเสริมแสง โทนสี และอารมณ์

## โครงสร้างภายในช่วง

**ช่วงเวลา + @อ้างอิงฉาก + ขนาดภาพ/การเคลื่อนกล้อง + @อ้างอิงตัวละคร + การกระทำหลัก·สีหน้า + บทพูด/เสียงบรรยาย + อารมณ์และแสง**

- **ช่วงแรกต้องสร้างบรรยากาศพื้นที่**: ฉาก + ตำแหน่งกล้อง + ตำแหน่งและสถานะของตัวละคร
- **การตัดช็อต**: เริ่มช่วงหลังการตัดด้วยคำเชื่อม เช่น "ตัดสลับไปที่ / ตัดกลับมาที่" และระบุขนาดภาพและตัวแบบใหม่
- **ขนาดภาพ/การเคลื่อนกล้อง**: ระบุสภาวะกล้องหนึ่งอย่างต่อช่วง (ภาพระยะใกล้ / ปานกลาง / มุมกว้าง / โคลสอัพ; กล้องนิ่ง / ดันเข้า / ดึงออก / แพน)
- **อารมณ์ทั้งหมดต้องเป็นคำอธิบายภาพที่มองเห็นได้**: ไม่ใช้คำนามธรรม ให้เขียนเป็นการกระทำ เช่น "ก้มหน้า มือบีบขอบแก้วแน่น หายใจติดขัด"
- **บทพูด/เสียงบรรยาย**: เขียนเป็น "ชื่อตัวละครพูดว่า: "ข้อความ""; เสียงบรรยายเขียนเป็น "เสียงบรรยาย: ข้อความ"
