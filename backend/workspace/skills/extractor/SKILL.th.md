# คู่มือการสกัดตัวละคร ฉาก และอุปกรณ์ประกอบฉาก

## กฎการสกัดตัวละคร

ฟิลด์ตัวละครที่สกัด (ตรงกับพารามิเตอร์ของ `save_dedup_characters` แบบ 1:1):
- **name** (จำเป็น): ชื่อเต็มของตัวละคร
- **role**: บทบาท — ตัวเอก (protagonist) / ตัวประกอบ (supporting) / ตัวสมทบ (extra)
- **appearance**: คำอธิบายรูปลักษณ์ (300-500 ตัวอักษร) — เพศ วัยโดยประมาณ เครื่องหน้า รูปร่าง บุคลิก **อย่าแยกนิสัยใจคอออกมาต่างหาก แต่ให้หลอมรวมเป็นบุคลิกภายนอกและสีหน้าที่ผสานในคำอธิบายรูปลักษณ์** (เช่น "นิสัยเย็นชา" ให้เขียนเป็น "สายตาเย็นชา สีหน้านิ่งสงบ ไม่ค่อยยิ้ม")
- **styling**: สไตล์ — ทรงผม เสื้อผ้า การแต่งหน้า เครื่องประดับ
- **description**: ประวัติเบื้องหลังและความสัมพันธ์ของตัวละคร (ข้อมูลเสริม)

## กฎการสกัดฉาก

ฟิลด์ฉากที่สกัด (ตรงกับพารามิเตอร์ของ `save_dedup_scenes` แบบ 1:1):
- **location** (จำเป็น): ชื่อสถานที่ชัดเจน
- **time**: ช่วงเวลา (เช่น กลางวัน / โพล้เพล้ / ดึก); สถานที่เดิมแต่คนละช่วงเวลานับเป็นฉากใหม่
- **prompt**: คำอธิบายฉาก — พื้นที่ การจัดวาง สภาพแวดล้อม องค์ประกอบภาพหลัก (ภาพฉากบริสุทธิ์ ไม่มีผู้คน)
- **lighting**: แสงของฉาก — แหล่งกำเนิดแสง โทนสี คอนทราสต์ความสว่าง อารมณ์ภาพ

## กฎการสกัดอุปกรณ์ประกอบฉาก

**หลักการสำคัญ: สกัดน้อยดีกว่าสกัดมากเกินไป** อุปกรณ์เป็นสินทรัพย์ที่มีต้นทุนสูงในการสร้างภาพสินค้าพื้นหลังขาวและใช้อ้างอิงการโคลสอัพในวิดีโอ สกัดเฉพาะอุปกรณ์ที่จำเป็นต่อพล็อตจริงๆ เท่านั้น ปกติหนึ่งตอนจะมีอุปกรณ์สำคัญ **0-3** ชิ้น หากมีมากกว่า 3 ให้จัดลำดับตามความสำคัญต่อพล็อตและเลือกเฉพาะ 3 อันดับแรก

ต้องผ่านทั้ง 2 เงื่อนไขนี้พร้อมกัน:
1. **ผลักดันพล็อตโดยตรง**: การปรากฏตัว ส่งมอบ เสียหาย หรือค้นพบสิ่งของทำให้เกิดจุดเปลี่ยนของเนื้อเรื่อง (เช่น อาวุธสังหาร ของแทนใจ เอกสารสำคัญ ของขวัญสารภาพรัก หลักฐานสำคัญ)
2. **คุ้มค่าต่อการสร้างภาพแยก**: สตอรี่บอร์ดจะมีช็อตโคลสอัพหรือปรากฏซ้ำ จึงจำเป็นต้องมีหน้าตาคงที่

**คำถามตรวจสอบ 3 ข้อ** (หากข้อใดตอบว่า "ใช่" ให้ตัดทิ้ง):
- (1) ตัดสิ่งนี้ออกไปแล้วพล็อตเรื่องยังดำเนินต่อไปได้ปกติหรือไม่? → หากใช่ **ไม่ต้องสกัด** (เป็นแค่ของประดับฉาก)
- (2) เป็นแค่ของใช้ทั่วไปในชีวิตประจำวันที่ตัวละครหยิบจับตามปกติหรือไม่ (โทรศัพท์ ตะเกียบ แก้วน้ำ บุหรี่ ร่ม)? → หากใช่ **ไม่ต้องสกัด**
- (3) เป็นส่วนหนึ่งของการจัดวางฉากหรือไม่ (โต๊ะเก้าอี้ โคมไฟ ประตูหน้าต่าง ภาพแขวนผนัง จานชาม)? → หากใช่ **ไม่ต้องสกัด** (สิ่งเหล่านี้อยู่ในคำอธิบายฉาก)

หากไม่มีอุปกรณ์ใดเข้าเกณฑ์ **อย่าฝืนสกัด** — ให้ส่งอาร์เรย์ว่างเมื่อเรียก `save_dedup_props`

ฟิลด์อุปกรณ์ที่สกัด (ตรงกับพารามิเตอร์ของ `save_dedup_props` แบบ 1:1):
- **name** (จำเป็น): ชื่ออุปกรณ์
- **type**: หมวดหมู่ — daily / weapon / transportation / decoration / document ฯลฯ
- **description**: รูปลักษณ์ทางกายภาพของสิ่งของเท่านั้น (วัสดุ สี รูปทรง ขนาด ระดับความเก่า ร่องรอยความเสียหาย); อย่าบรรยายพล็อตหรือความสัมพันธ์กับตัวละคร

อุปกรณ์**ไม่จำเป็นต้องมี prompt สำหรับสร้างภาพ** — prompt สุดท้ายของอุปกรณ์จะถูกสร้างโดย Prompt Generator Agent ก่อนสร้างภาพจริง

## ขั้นตอนการทำงาน

1. เรียกใช้ `read_script_for_extraction` เพื่ออ่านบทของตอนปัจจุบัน
2. เรียกใช้ `read_existing_characters` เพื่อดูตัวละครที่มีอยู่แล้วของโปรเจกต์
3. เรียกใช้ `read_existing_scenes` เพื่อดูฉากที่มีอยู่แล้ว
4. เรียกใช้ `read_existing_props` เพื่อดูอุปกรณ์ที่มีอยู่แล้ว
5. สกัดเฉพาะตัวละคร ฉาก และอุปกรณ์ที่เกี่ยวข้องกับตอนปัจจุบันจริงๆ
6. เรียกใช้ `save_dedup_characters` เพื่อบันทึกตัวละครและผูกกับตอนปัจจุบัน
7. เรียกใช้ `save_dedup_scenes` เพื่อบันทึกฉากและผูกกับตอนปัจจุบัน
8. เรียกใช้ `save_dedup_props` เพื่อบันทึกอุปกรณ์และผูกกับตอนปัจจุบัน
